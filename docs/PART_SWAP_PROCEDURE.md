# 부품 교체 절차 (실물)

기술서 수준의 증명은 끝났다(`tools/swap_demo.py`). 이 문서는 **실물로 바꿔 끼울 때**
사람이 지켜야 하는 순서다. 소프트웨어가 대신할 수 없는 부분이다.

## 손 교체

| 순서 | 하는 일 | 확인할 것 |
|---:|---|---|
| 1 | 정지 | 화면에서 멈춤. 모터가 완전히 선 것을 눈으로 확인 |
| 2 | 전원 차단 | 팔 전원을 내린다. 통신만 남긴다 |
| 3 | 물리 교체 | 잠금 해제 → 분리 → 새 손 결합 → 잠금 |
| 4 | 기술서 교체 | `install/modules/hand_*.json`을 새 손 것으로 |
| 5 | 구성 확인 | 화면에 새 손 이름·단위가 뜨는가. 하중 경고가 없는가 |
| 6 | 검증 취소 확인 | **손 관련 "해봤음"이 사라졌는가.** 팔은 그대로인가 |
| 7 | 무부하 시험 | 저속으로 열고 닫기. 물건 없이 |
| 8 | 저하중 시험 | 가벼운 것으로 집기 |
| 9 | 검증 기록 | 실제로 해봤을 때만 "해봤음"으로 올린다 |

**하지 않는 것**: 움직이는 중 교체, 검증 없이 자동 실행, 하중 경고 무시.

## 축 변경 (고장 등으로 축을 뺄 때)

| 순서 | 하는 일 |
|---:|---|
| 1 | 정지 후 해당 축의 상태 확인(고장인지 잠긴 것인지) |
| 2 | 기술서에서 그 관절에 `"disabled": true`와 사유를 적는다 |
| 3 | 화면 관절 표시가 따라 줄었는지 확인 |
| 4 | 팔 검증이 내려갔는지 확인 (다른 부품은 그대로여야 한다) |
| 5 | 그 축을 쓰던 저장 자세가 막히는지 확인 |
| 6 | 남은 축으로 되는 작업만 다시 가르친다 |

## 교체 후 반드시 다시 하는 것

- 그 부품이 관여하는 작업의 **발음(관절값)을 다시 가르친다.** 뜻은 남아 있다.
- 검증은 **사람이 실제로 해본 뒤에만** 올린다.
