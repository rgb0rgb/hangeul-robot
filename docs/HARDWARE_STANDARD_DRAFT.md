# 한글 로봇 부품 규격 초안 (C15)

- 상태: **초안 0.1.** 업계 표준이라고 주장하지 않는다.
  서로 다른 제조사 부품 둘을 실제로 바꿔 끼워 본 뒤에 정식 규격으로 올린다.

## 세 층으로 나눈다

| 층 | 누가 정하는가 | 우리 위치 |
|---|---|---|
| 기계 (결합면·볼트·정렬) | 기존 산업 표준 (로봇 툴 플랜지 등) | **따른다** |
| 전기 (전압·전류·핀 배치) | 기존 표준 (산업용 버스) | **따른다** |
| **데이터 (신원·능력·기구학·교정)** | 비어 있다 | **여기를 정의한다** |

기계·전기는 큰 회사와 표준화 기구가 정한다. 우리가 지금 정의할 수 있고
비어 있는 층은 **부품이 자기를 소개하는 방법**이다.

## 부품이 밝혀야 하는 것

```json
{
  "module_id": "제조사:모델:일련번호",
  "module_class": "arm | hand | eye | ear | mobility",
  "mount": "어디에 꽂히는가",
  "provides": ["이 부품이 주는 능력"],
  "requires": ["필요한 것 (전원·버스·결합면)"],
  "limits": {"payload_g": 0, "mass_g": 0},
  "safety_class": "motion | pinch | vacuum | rotating | thermal | observe",
  "stop_path": "위험 등급이면 필수 — 이 부품을 멈추는 방법"
}
```

## 규칙

1. **모르는 부품은 등록은 되되 움직임에는 쓰이지 않는다.**
2. 위험 등급(회전·고온·흡착)은 **전용 정지 경로 없이 꽂히지 않는다.**
   팔이 멈춰도 드릴은 관성으로 돈다. 팔 정지와 부품 정지는 다른 일이다.
3. 부품이 바뀌면 그 부품의 검증만 내려간다. 다른 부품의 검증은 건드리지 않는다.
4. 하중·전력·결합면이 맞지 않으면 **꽂히기 전에** 거절한다.

## 벤더 동의 없이도 성립하는 이유

기존 하드웨어를 감싸는 어댑터가 기술서를 대신 제출하면 된다.
지금 OMX와 MyCobot을 그렇게 다루고 있고, 그것이 첫 증명이다.
