# 반복 작업 모드

작성: 2026-09-24 · 적용 대상: 한글 로봇 콘솔

미세 이동 전용 모드 아래의 **반복 작업 모드**에서 관절 또는 손 하나를 골라 두 위치 사이의 동작을 반복합니다. 자세를 저장하거나 실행 순서에 같은 동작을 여러 번 넣을 필요가 없습니다.

## 사용 방법

1. 작업할 로봇을 선택합니다.
2. 반복 작업 모드의 **관절 / 손**을 선택합니다.
3. **A 위치**, **B 위치**를 입력합니다. 원하는 위치로 먼저 이동한 뒤 **현재값 → A/B**로 읽어 넣을 수도 있습니다.
4. **반복 횟수**, **A 대기**, **B 대기**를 설정합니다.
5. **반복 시작**을 누르고 기존 안전 확인 창에서 확인합니다.

**1회 = A로 이동 → A에서 대기 → B로 이동 → B에서 대기**입니다. 50회는 100번의 위치 이동이며, 마지막은 B에서 끝납니다. 시작 위치로 자동 복귀하지 않습니다. 화면에 완료 횟수와 현재 회차·A/B 단계가 표시됩니다.

| 작업 | 설정 예 |
|---|---|
| 관절 1 왕복 | 관절 1, A=1300, B=2000, 횟수=50 |
| 그리퍼 열고 닫기 | 손, A=해당 로봇의 열림 값, B=닫힘 값, 횟수=10 |
| 회전 관절로 번갈아 뒤집기 | 해당 회전 관절, A/B=양쪽 각도, A/B 대기=각 면에서 머무를 시간 |

1300·2000은 예시입니다. 화면에 표시되는 해당 관절의 허용 범위를 따라야 합니다. OMX는 틱, MyCobot 팔은 도, MyCobot 손은 퍼센트로 입력합니다. 실행 속도는 느림입니다. 열림·닫힘 방향과 허용 위치는 로봇마다 다르므로 임의의 최대·최소값을 자동 입력하지 않습니다.

## 동작으로 저장하기

반복 설정을 **한 장의 동작 카드**로 저장할 수 있습니다. 저장되는 것은 관절/손, A·B 위치, 반복 횟수, A 대기, B 대기입니다.

- 반복 칸을 채운 뒤 **반복 작업 자세 저장** 또는 아래쪽 **💾 자세 저장**을 누르면 저장 방식이 **반복 작업 함께 저장**으로 잡힙니다. 반복 칸이 비어 있으면 평소처럼 현재 자세를 저장합니다.
- 저장된 카드를 실행하거나 실행 순서에 넣으면 저장한 횟수만큼 반복한 뒤 다음 단계로 넘어갑니다.
- 카드 편집에서 횟수·위치·대기를 바꿀 수 있습니다. 잘못된 값이면 기존 카드를 덮어쓰지 않습니다.
- 저장은 로봇을 움직이지 않습니다.
- 순서 실행 중 **취소·일시정지·재개**는 진행 중인 반복에도 전달됩니다. 진행 중인 이동이 끝난 뒤 다음 이동 전에 섭니다.

## 정지와 재개

- **이동 후 일시정지**: 진행 중인 이동이 반환된 뒤 다음 이동 전에 멈춥니다. 대기 중이면 남은 대기 시간도 멈춥니다.
- **재개**: 일시정지한 지점에서 이어갑니다.
- **취소·정지**: 반복을 취소하고 런타임에 비상 정지를 요청합니다. 다시 시작하려면 기존 정지 해제 절차가 필요합니다. 정지 응답이 확인되지 않으면 화면에 표시합니다.
- 기존 비상 정지도 반복을 취소합니다. 일시정지는 즉시 비상 정지를 대신하지 않습니다.

반복은 콘솔 서버가 실행합니다. 브라우저 새로고침·닫기로 취소되지 않으며, 같은 로봇을 다시 선택하면 진행 상태를 읽습니다. 콘솔 프로세스를 재시작하면 반복을 자동 복원·재개하지 않습니다. 서버 종료는 하드웨어 비상 정지 명령을 대신하지 않으므로 작업 중 서버를 종료하지 마십시오.

## 적용 범위와 검증

현재는 **한 관절 또는 한 그리퍼의 두 위치 반복**입니다. 여러 관절을 동시에 바꾸는 두 자세 반복, 무한 반복, 위치 제한을 넘는 연속 360도 회전은 이번 기능에 포함되지 않습니다. 회전형 도구도 현재 어댑터가 지원하는 위치 명령과 허용 범위 안에서 사용할 수 있습니다. 석쇠 장착 시 하중·열·충돌·실제 정지 성능은 별도로 확인해야 합니다.

두 목표를 실행 전에 검사하고, 각 이동은 기존 실행 경로의 안전·능력·장치 임대 검사를 통과해야 합니다. 구성이나 연결 대상이 바뀌거나 이동 결과가 실패하면 다음 위치로 진행하지 않습니다. 같은 런타임을 사용하는 반복 작업과 저장 순서의 중복 시작을 막습니다. 반복 중 콘솔 수동 이동·저장 자세 실행·시운전·추적 이동 시작도 차단합니다. 런타임에 직접 접근하는 외부 제어기를 배타적으로 관리하는 기능은 아닙니다.

자동 검증은 실제 하드웨어를 호출하지 않습니다.

```bash
python3 -m pytest -q tests/test_repeat_work.py tests/test_screen_contract.py
python3 tools/verify_repeat_work_ui.py
```

브라우저 검증은 실제 반복 패널·JavaScript·콘솔 API를 연결하고, 이동·상태 읽기·정지 통신은 모의 처리합니다. 50회/100번 이동, 그리퍼 현재값 입력, 일시정지·재개·취소, 영어 전환을 확인합니다. 기존 안전 확인 창과 단위 변환 도우미는 이 브라우저 검증에서 대체합니다. 실물 반복 시험은 수행하지 않았습니다.
